# 运行治理与维护

本轮以 Engine `24c9d8a` 的业务事实和格式15为迁移基线。Core 不改动；Design
使用已提交版本的固定快照，未提交修改不进入依赖。实现分布于组件健康、请求账本、
分析领取账本和正文归档；领域端口不依赖 SQL、配置文件或传输 SDK。

## 健康与诊断

`EngineHost.query_health()` 和 `GET /api/health` 在启动期间也可查询，不读取数据库。
生命周期 phase 和组件健康独立表达。组件所有者锁存首次故障的时间、稳定错误码、
关联 ID 和处理资格；同一原因链跨层传播复用关联 ID，仅第一个所有者报告主 ERROR。
正常取消不构成组件故障。存储可读时仍可核对历史，故障不会被空闲会话掩盖。

模型服务报告最终模型失败，能力派发报告逐调用结果，执行服务报告行动汇总；
存储内部正常事件仅为 DEBUG。终端输出中文摘要，文件保留异常类型、原因链、
异常组和模块／函数／行号。第三方异常正文、请求正文、源代码行和局部变量不写入日志。
文件仍遵守独立轮转上限。嵌入式 Engine 不安装日志处理器或信号处理器。

CLI 在读取配置前安装终端日志，取得目录锁后通过应用回调安装文件日志。
配置、插件声明、数据库、模型、插件构建与启动、主体恢复及 WebUI 分段计时。
WebUI 可先于宿主就绪监听。主动插件连接期间可先保存输入，公开业务操作及模型
调度须等待全部插件就绪；启动失败走统一收尾。生命周期进入 running 不替代
健康接口中的实际处理资格。
浏览器插件只在第一次明确使用时初始化会话，初始化与关闭由同一所有者锁串行保护。

## 分析调度与共享成本

行为评审和记忆整理分别持有队列进度、开关、任务、会话和健康。可靠反馈桥接不受
这两个开关控制。两种分析均每批从空模型历史开始，不恢复上一批检查点，也不维护
跨批摘要；请求证据、轮次、工具交付和实际呈现资格照常持久化。

行为评审默认有待办满60秒或新增8个成功前台轮次触发；记忆整理默认30分钟或32轮。
人工评价优先，满批时为普通来源保留一席。已经触发的观察窗口内，溢出来源和成功
复核后的续页继续处理，不要求新输入。每批最多32个来源、8个逻辑请求及600秒。

`analysis_work` 按用途、来源版本和实际证据页领取，区分 pending、processing、
retry_wait、waiting_evidence、capacity_blocked 和 completed。epoch 仅是观察边界。
完成只采用成功结案的连续覆盖前缀；领取游标或读取原文都不代表已经理解。
失败最多尝试三次，第一次失败等待60秒，第二次等待300秒，耗尽后等待相关新证据。
准备阶段也受同一整批绝对期限约束；准备超时保留未领取范围并采用同样的有限退避。
明确 input／turn／action／call 因果身份或 `related_evidence_ids` 才能唤醒相关旧范围；
无关新来源不刷新尝试次数。延期等待证据，容量阻塞等待实际容量策略变化。

冻结批次前先构造 Core 的完整首发预览，纯编译后计算提示、工具、动态材料、原文和
媒体的容量。超限先减少来源，再缩小合法证据页；结构化材料不可任意截断。
单项仍不适配则保留容量阻塞，不消耗传输额度，也不妨碍其他来源。

两个后台任务共享滚动一小时32次真实传输尝试，模型重试同样计数。每次尝试在进入
后端前由请求账本事务核验并持久化；重启不刷新额度。预算拒绝是正常等待，不使 Store
失效，也不消耗来源失败次数。面板显示最近调度观察、等待原因和额度恢复时间。

## 两种分析责任

行为评审提供 `recall`、`read_evidence`、`supervise` 和 `submit_behavior_review`。
审查包带相关刺激、实际行动与回执、人工意见和有限近期样本。程序产生的重复表达
统计仅是待核验线索，不能直接提交纠偏。结论允许无需干预、局部建议或证据不足。

建议必须提供真实呈现的证据、明确适用范围、预期改善和期限；泛化建议至少需要
两个独立来源。同问题与范围的有效建议查重，复用可靠反馈交接。前台接受、部分接受
或拒绝单独保存，不算行为改善。建议最多观察7天或20个相关成功轮次；后续观察必须
引用真实机会证据。存在复发即记录复发；至少三次有据改善且未复发才记录已有改善，
否则为样本不足。到期、机会耗尽、前台回应和观察结论分别呈现。

记忆整理提供 `recall`、`read_evidence`、`revise_memory` 和 `finish_reflection`。
它拥有查重、修订和来源结案责任，不能消掉行为评审待办。实际版本、事务提交和
原文呈现资格继续核验；没有证据不能写纠偏或记忆，不为结案强行产生新认识。

人工评价支持实际行动、前台轮次和能力调用。没有行动的轮次可以评价遗漏回应，
不创建虚构行动。完整审查材料、revision 复核、稳定控制身份及事务投递规则一致。

## 诊断正文与空间

格式16将完整请求材料、响应／参数事件及已安装摘要的调试副本放入可淘汰正文表。
请求身份、结果、用量、因果关系、原始字节数、摘要和幂等校验依据长期保留。
正文查询明确给出可用性、淘汰时间与原因，不能用空字符串冒充完整材料。

默认按7天或合计1 GiB，优先淘汰最旧可清理正文。流诊断计入同一容量。
请求和响应按可还原的完整逻辑正文计量，BLOB 指针不能绕过容量上限；
实际媒体仍按内容去重，因此逻辑正文统计不能与物理媒体大小相加作为文件大小。
当前请求、在途会话和未安装摘要的验证材料受保护。用量锚点独立保存指纹及
实际 token 数，引用请求身份不永久保护其完整诊断正文。当前检查点、
未决工作、长期记忆来源及其独立证据不依赖诊断副本，继续可读。保护项可导致
诊断暂时超额；此策略不承诺整个数据库固定大小。

在线清理由唯一 Store 队列逐批提交，最多128项和16 MiB；单项超大时允许独占
一批以取得进展。媒体仍按 SHA-256 去重，仅在所有存活外键引用都消失后回收。
媒体回收也采用独立的条数与字节预算。维护按周期检查，存在积压时逐批继续；
保留上限属于淘汰策略，不是阻止新诊断接管的磁盘配额。
清理不会重写业务回执或删除输入；不自动 VACUUM。

普通面板只读取会话版本、活动轮次和最近维护统计，不恢复 checkpoint 或媒体。
行动历史、输入反查轮次和人工评价关联有索引；同时间以稳定身份排序。
语义检索按模型和有效性分页读取候选，向量解析与精确计算在数据库线程外执行，
返回前再次核验版本资格，不引入近似向量库。

## 离线维护

先停止同目录 Engine。下列命令使用同一目录锁，不装配模型、插件或宿主：

```powershell
purrcept-engine db-check --data-dir C:\data\purrcept
purrcept-engine db-stats --data-dir C:\data\purrcept
purrcept-engine db-clean --data-dir C:\data\purrcept
purrcept-engine db-vacuum --data-dir C:\data\purrcept
```

`db-check` 执行完整 quick_check 和外键检查。`db-stats` 汇总文件、WAL、空闲页、
各类逻辑正文及保护原因并更新面板缓存。`db-clean` 使用默认保留策略，可通过
`--config 配置文件 db-clean` 使用配置策略。`db-vacuum` 显式压缩空闲页。
输出分别报告淘汰字节、可复用空间和实际文件前后大小；没有执行压缩不能宣称文件缩小。

只有格式15可以一次性原子迁移到16，迁移前后都保留原始业务事实和未决责任。
迁移提交前完整检查，失败回滚所有结构和数据。格式12—14及未知格式直接拒绝。
正常格式16启动保留必要结构、记录与恢复校验，完整审计移到维护命令。

## 验证与效果评估

测试默认使用临时目录、合成材料和模型替身。数据库破坏性维护只在临时库验证，
不会读取或清理真实运行数据。真实模型、消息和设备需另行安排。

`scripts/benchmark_store.py` 在固定合成规模记录启动、面板和历史查询计时及索引计划；
比较应使用同一机器、数据规模和 Python 环境，不把单次测量推广为实际提速比例。
启动日志的分段计时用于定位真实运行瓶颈，不包含设备或网络效果承诺。

固定评审样本位于 `tests/fixtures/review_samples.json`。两组结果以同一组样本 ID
写入 JSON，每项含 `id`、`decision`，可选实际 `usage`、独立审查的 `memories`、
后续行为 `observations` 和 `feedback_wait_seconds`。用量字段为 input_tokens、
output_tokens、cached_input_tokens，缓存已包含在输入中。运行：

```powershell
python scripts/evaluate_reviews.py --samples tests/fixtures/review_samples.json --baseline baseline.json --candidate candidate.json
```

比较器核验样本完整对应，统计漏检、误干预、每条有效建议 token、记忆重复及错误泛化。
缺少实际用量、独立记忆标注或后续观察就输出未知，不把替身测试当作真实纠偏改善率。
